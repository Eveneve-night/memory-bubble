# 忆泡 Memory Bubble · 原型说明

- 文件：`prototype.html`（单文件，约 2,670 行 / 93 KB，内联 CSS/JS/SVG）
- 打开方式：直接双击，或用 Chrome / Edge 以 `file://` 打开。无 CDN、无 import、无 fetch，断网可用。
- 自检：已抽取 `<script>` 内容执行 `node --check`，通过；页面无网络请求（唯一的 `http://` 是 SVG 命名空间字符串）。

## 已实现的 10 条交互

1. **暖调泡泡视觉**：奶油底 + 多层径向光晕；五组蜜桃/珊瑚/杏黄/暖粉/奶茶渐变气泡，白高光、内发光、1px 半透明白描边；气泡缓慢呼吸漂浮，`prefers-reduced-motion` 下全部停用。
2. **画布**：滚轮以光标为锚点平滑缩放（0.25×–2.5×，带缓动）；空白拖拽平移；双击空白适应窗口；`ctrl + wheel`（触控板双指）同样走缩放。
3. **语义缩放三档**：<0.5 远景色块无文字；0.5–1.2 中景短标题；>1.2 近景展开摘要首行 / 记录时间 / 关键词 chips / 连线关系短标签。左下角常驻档位与百分比指示。
4. **节点**：hover 出现光环并高亮相邻边；单击右侧滑入玻璃详情卡（标题、摘要、时间、chips、重要性滑杆、引用/编辑/删除）；滑杆实时改半径（240ms 过渡）；编辑可改标题与摘要；删除需二次点击「确认删除」。
5. **连线**：单击打开关系卡（关系说明、两端记忆、编辑关系、删除连线）。示范冲突边为「先结论 ↔ 技术推导」：虚线 + 砖红，卡片顶部警告条，两端节点虚线警示描边；「重新校验」模拟 1s 后提示「未发现冲突」并恢复普通连线。
6. **引用到对话**：卡片按钮或 Shift + 单击节点，加入底部记忆托盘（可移除）；「注入本轮对话」toast「已加入本轮记忆提示（N 条）」并清空托盘；托盘在画布下方，不遮挡图。
7. **搜索**：匹配标题 / 关键词 / 摘要；命中节点放大、其余降透明，边只保留两端都命中的；顶部状态条显示命中数；清空恢复。
8. **演示数据与布局**：20 条记忆、25 条关系（1 条冲突）；自实现径向力导向：黄金角初值 + 斥力 + 碰撞 + 弹簧 + 频率径向锚，迭代后归一化并居中；渲染时用 CSS 动画做 float 偏移，不改布局坐标。
9. **新增记忆**：右下角按钮，在质心附近找空位生成随机新记忆，自动连到最近节点，toast 提示「AI 总结出一条新记忆」。
10. **性能**：全部 SVG（约 20 节点 / 25 边），缩放平移只改单个 `<g transform>`，rAF 合并；mousemove 不重建 DOM；标签避让只在档位 / 数据 / 选中变化时计算。

## 操作速查

- 缩放：滚轮 / 触控板双指；平移：拖拽空白；适应窗口：双击空白。
- 节点：单击看详情，Shift + 单击放进托盘；连线：单击看关系。
- 搜索框输入即筛；`Esc` 先关卡片，再清搜索。
- 重要性滑杆实时改气泡大小；编辑后保存即时生效。

## 已知取舍

- **节点位置不可拖**：按需求位置只由出现频率和关系决定，用户只能平移/缩放整张图。
- **近景不会一次展开全部详情**：20 个节点的摘要/时间/chips 同屏必然叠字，所以近景按「重要度 + 是否在视野内 + 选中/悬停」只自动展开少数（通常 3–6 条），其余显示短标题，hover 或选中时再展开；中景个别标签实在放不下会隐藏。这是刻意的信息降噪。
- **标签可翻到气泡上方**：近景空间不足时短标题会上移，极少数情况下与上方气泡贴得较近，归属感略弱。
- **冲突校验是模拟**：「重新校验」固定 1s 后清除 `conflict`，不接真实模型。
- **状态不持久化**：编辑、删除、滑杆、新增都只存在内存，刷新还原（避免 file:// 下的存储差异）。
- **新增节点不重排全图**：只在质心附近找空隙并连最近节点，保证已看过的布局不跳。
- **手势范围**：只做双指缩放，未做双指平移；窄屏为收缩布局，不是独立移动端设计。
